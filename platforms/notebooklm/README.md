# NotebookLM 与仅支持对话指令的产品

NotebookLM 的资料来源（Sources）和聊天自定义响应指导，并不等同于一个自动执行本地参考文件的 Agent Skills 运行时。这里提供**便携 Prompt**，避免误称“原生 Skill 已安装”。

建议流程：
1. 将具备使用权的原文、PDF 或文章作为来源导入 NotebookLM。
2. 将 [便携指令](../portable/PORTABLE-PROMPT.md) 的相关部分放入当前可用的对话指导/提问中。若产品指令长度有限，优先保留“S1–S4 + 证据边界 + 阅读模式”。
3. 提问时明确范围，例如“只做 L2 检视阅读”“仅分析已导入的第 2–4 章”“只给出有原文依据的批判评价”。
4. 对自动生成的引文、章节、归因进行人工核对；不能把 NotebookLM 的概述自动视为已完成跨书主题阅读。
