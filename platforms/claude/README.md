**Claude Code 等原生支持 Agent Skills 的宿主**：使用 `skills/analytical-reading/` 整目录，按所在客户端当前官方说明安装；保留相对的 references 资源。

两个方式的安装机制不同，不能仅因提示词能够工作就称为“原生 Skill 已安装”。保持 S1–S4 证据边界和版权/隐私控制。
